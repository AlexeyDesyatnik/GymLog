# Plan notation uses "/" instead of "x"

Plans are typed as text on a phone. The paper notation `80 x 5 x 3` needs a switch between the letter and number keyboard modes for every `x`, because phone number layouts have no `x`. We use `/`, which is on the first number page on both iOS and Android: `bench press 80/5/3 70/8`, with groups separated by spaces and an empty field for no weight (`pull-up /8/3`). After the name, a whole line is typed in number mode. `x`, `х`, `×` and `*` are still accepted on input, but Plans are shown with `/`.

This still needs checking on a prototype on the users' actual phones, since some keyboards return to letters on their own after a space or punctuation.
